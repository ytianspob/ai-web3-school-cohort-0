# 主方向阅读摘要：Agent Wallet

## 1. ERC-4337（Account Abstraction）

### 它解决什么问题

传统钱包（EOA）只有“持有私钥才能操作资产”这一种模式，权限控制非常粗糙。

ERC-4337 通过账户抽象（Account Abstraction）让钱包变成可编程账户，可以实现：

* Session Key
* Spending Limit
* Social Recovery
* Policy Control
* Batch Transaction

对于 Agent Wallet 来说，可以让 Agent 在有限权限下执行任务，而不需要长期持有主私钥。

### 边界是什么

ERC-4337 解决的是：

* 钱包执行层
* 权限控制层
* 用户体验层

它不解决：

* Agent 如何理解用户意图
* 风险分析
* Prompt Injection
* Agent 决策逻辑

### 还缺什么

要构建完整 Agent Wallet，还需要：

* AI Intent Layer
* Risk Engine
* Human Approval Flow
* Audit System

## 2. Safe Smart Account

### 它解决什么问题

Safe 提供多签和智能账户能力。

核心价值：

* 多人共同控制资产
* 交易审批流程
* Guard / Policy 机制
* Treasury 管理

对于 DAO 和团队钱包尤其重要。

### 边界是什么

Safe 解决的是：

* 资产控制
* 执行授权
* 多签治理

它不解决：

* AI Agent 如何工作
* 用户意图解析
* 自动化策略生成

Safe 更像执行层基础设施。

### 还缺什么

如果想成为 Agent Wallet：

还需要增加：

* 自然语言入口
* Agent Planner
* Risk Scoring
* Automated Workflow

否则只是智能账户而不是 Agent 系统。

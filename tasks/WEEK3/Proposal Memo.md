## 1. 目标用户

本项目面向以下三类用户：

* 普通 Web3 用户（不熟悉 DeFi 协议，但希望安全使用链上资产）
* DAO / 小型金库管理者（需要执行资金操作但缺乏自动化工具）
* 有一定经验的 DeFi 用户（希望提升效率并降低操作复杂度）


## 2. 真实场景

用户在日常使用 DeFi 时通常面临以下问题：

* 不清楚哪个协议收益更优
* 手动操作 swap / deposit / approve 流程复杂
* 容易误操作或授权过度
* 每次交易都需要理解合约细节

典型场景：

用户输入自然语言指令：

“帮我把 100 USDC 存入收益较稳定的协议”

系统需要自动完成：

* 理解用户意图
* 分析可选协议
* 生成执行方案
* 提示风险
* 用户确认后执行交易
* 记录执行结果


## 3. 最小功能（MVP）

Week 4 可实现的最小闭环功能：

* 钱包连接（MetaMask）
* 自然语言输入解析（AI Agent）
* 结构化交易计划生成
* 基础风险提示（金额 / 协议 / 操作类型）
* 人工确认机制（Human-in-the-loop）
* 模拟或真实交易执行
* 执行日志记录与展示


## 4. 验证方式

验证目标：

用户是否可以通过自然语言安全完成链上操作，并理解执行过程。

测试方法：

* 5–10 名 Web3 用户参与测试
* 给定统一任务（如存入 50 USDC）
* 观察执行流程完成率

关键指标：

* 任务完成率 ≥ 80%
* 用户理解风险提示
* 无未经确认的资金操作
* 每一步执行可追溯

## 5. 风险边界

### 安全风险

* Prompt Injection 导致错误执行
* 恶意合约诱导交易
* 无限授权（approve）风险

### 权限风险

* Agent 权限过大导致资产暴露
* Session Key 或签名机制泄露

### 系统风险

* AI 生成错误交易路径
* 风险评估误判
* 依赖外部价格或协议数据错误

### 控制机制

* 高风险操作必须人工确认
* 白名单协议限制
* 预算与金额上限
* 所有操作可审计记录
